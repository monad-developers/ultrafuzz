`findings.json` must be a JSON array. Use `[]` when there are no findings. Every finding must set `schema_version` to exactly `"ultrafuzz.finding.v2"` and include `id`, `title`, `status`, `severity_guess`, `confidence`, and `summary`. `status` is exactly one of `candidate`, `needs-review`, `duplicate`, `false-positive`, `confirmed`, `fixed`, or `wont-fix`; `severity_guess` is the preliminary estimate and is exactly `High`, `Medium`, or `Low`; `confidence` is exactly lowercase `high`, `medium`, or `low`. Do not use `severity` as a replacement for `severity_guess`; later severity review owns the final `severity`. If present, `triage_classification` is one of `true-positive`, `false-positive`, `undetermined`, `incomplete-spec`, `harness-defect`, `repair-candidate`, `spec-gated`, or `defensive-hardening`. Unknown fields are invalid. Evidence entries are either non-empty strings or closed objects using only `kind`, `path`, `line`, `symbol`, `command`, `summary`, `observed`, and `expected`.

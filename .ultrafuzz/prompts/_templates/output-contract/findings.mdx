`findings.json` must be a JSON array. Use `[]` when there are no findings. Each finding object must include non-empty string fields `schema_version`, `id`, `title`, `status`, `severity_guess`, `confidence`, and `summary`. Use `schema_version: "1.0"`. `status` must be one of `candidate`, `needs-review`, `duplicate`, `false-positive`, `confirmed`, `fixed`, or `wont-fix`. If you include `triage_classification`, use one of `true-positive`, `false-positive`, `undetermined`, `incomplete-spec`, `harness-defect`, `repair-candidate`, `spec-gated`, or `defensive-hardening`. Use `severity_guess`; do not use `severity` as a replacement.

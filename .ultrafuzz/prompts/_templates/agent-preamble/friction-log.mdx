## Friction Log

If Ultrafuzz tooling, the sandbox, or these instructions block or slow this task in a way you cannot fix within it, record it in the run friction log at `{{friction_log_directory}}` and keep working.
First read the `title:` line of every `*/friction.md` already there; if the same problem is recorded, add nothing.
Otherwise create `{{friction_log_directory}}/<UTC time as YYYYMMDDHHMMSS>-<first three title words, lowercase, hyphenated>/friction.md` that starts with this front matter, with any `'` inside a value doubled:

```
---
title: '<one specific line>'
severity: '<blocker, major, or minor>'
---
```

After it, write exactly these sections in order: `## Expected Behavior`, `## Current Behavior`, `## Possible Solution`, `## Minimal Reproducible Example`, `## Context`.
Write nothing else in that directory. Describe only the tooling problem. Never include target source, findings, vulnerabilities, secrets, or the target's identity.
